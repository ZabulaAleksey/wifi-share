# WiFi Share

Локальная передача, просмотр и воспроизведение файлов между устройствами в одной Wi‑Fi сети.

## Требования для сборки

- Go 1.25+
- Node.js 20.19+ или 22.12+
- npm

Готовый `wifi-share.exe` не требует установленных Go и Node.js.

## Где указать папку и пароль

Все локальные настройки находятся в файле:

```text
config.local.json
```

Этот файл включён в `.gitignore` и **не отправляется в GitHub**. В репозитории находится только безопасный образец `config.example.json`.

При первом запуске скопируйте образец:

```powershell
Copy-Item .\config.example.json .\config.local.json
notepad .\config.local.json
```

Пример содержимого:

```json
{
  "address": ":8080",
  "root": "C:\\Users\\Public\\Shared files",
  "data": "./data",
  "web": "./web/dist",
  "password": "ваш-сложный-пароль"
}
```

- `root` — папка, доступная другим устройствам;
- `password` — пароль полного доступа;
- `address` — порт сервера;
- `data` — приватная SQLite и служебные данные;
- `web` — собранный интерфейс.

Пароль даёт право загружать, создавать, переименовывать, редактировать и удалять файлы. Без входа доступен безопасный режим просмотра и воспроизведения.

Не размещайте `data` внутри `root`. Никогда не добавляйте `config.local.json` в Git.

## Запуск готового приложения

Откройте PowerShell в папке проекта:

```powershell
cd C:\MAMP\htdocs\wifi-share
.\wifi-share.exe
```

Программа сразу напечатает доступные адреса:

```text
WiFi Share is ready. Open one of these URLs:
  http://localhost:8080
  http://192.168.1.15:8080
```

На компьютере используйте `localhost`. На телефоне или другом устройстве откройте адрес `192.168...`; устройства должны находиться в одной Wi‑Fi сети.

Путь всё ещё можно временно переопределить аргументом запуска:

```powershell
.\wifi-share.exe -root "D:\Media"
```

## Сборка

```powershell
cd web
npm ci
npm run build
cd ..
go test ./cmd/... ./internal/...
go build -o wifi-share.exe ./cmd/wifi-share
```

## Разработка

В первом терминале:

```powershell
go run ./cmd/wifi-share
```

Во втором терминале:

```powershell
cd web
npm install
npm run dev
```

Откройте `http://localhost:5173`. Vite перенаправит API-запросы на Go-сервер с портом `8080`.

## Поведение удаления

На Windows удалённый через интерфейс файл перемещается в системную корзину компьютера. Его можно восстановить обычным способом через Проводник.

Архитектурные решения находятся в [ARCHITECTURE.mdx](./ARCHITECTURE.mdx).
## Системный трей

После запуска WiFi Share остаётся в системном трее Windows. Меню значка содержит: «Открыть», «Показать URL», «Выбрать папку», «Настройки» и «Завершить». Выбранная папка применяется сразу и сохраняется в config.local.json.

## Плейлист папки

При открытии аудио или видео очередь формируется из всех медиафайлов текущей папки. После завершения файла автоматически начинается следующий. После последнего файла воспроизведение останавливается.
